# AI Movie Studio — Android Starter

This is a starter Android project with a GitHub Actions workflow that builds a debug APK.

## Important status
This is only the initial application shell and build pipeline. It is **not yet** the advanced editor described in the project plan. Voiceover transcription, semantic image matching, multi-track timeline, effects, audio mixing and video rendering still need to be implemented and tested.

## Build on GitHub
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root (not the enclosing ZIP folder).
3. Open the **Actions** tab and allow workflows if prompted.
4. Run **Build Android APK** using **Run workflow**, or push a commit to `main`.
5. Open the completed workflow run and download the `ai-movie-studio-debug-apk` artifact.
6. Extract the downloaded artifact ZIP to get `app-debug.apk`.

The APK is a debug build for testing. It is not a Play Store release.
